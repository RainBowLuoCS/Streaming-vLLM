# Streaming-vLLM
An ultra-fast, lightweight streaming multi-modal inference engine based on Nano-vLLM. Designed for infinite context in real-time GUI/CLI Agent interactions.

## Key Features
* 🚀 **Infinite Context Streaming** - Decoupled KV Cache eviction with exact 3D MRoPE position mapping. Never OOM, never degrade.
* 👁️ **Multi-Modal Native** - Full support for Qwen3-VL, including DeepStack feature injection and linear-accelerated Conv3D patch embedding.
* ⚡ **Optimization Suite** - Tensor Parallelism (TP) for both Language and Vision models, CUDA Graph decode acceleration, and Zero-fragmentation KV Cache management.
* 📖 **Readable Codebase** - Clean implementation tailored for real-time video commentary and GUI agents.

## Quick Start
See `streaming_vl_test.py & streaming_test.py` for usage. The API extends vLLM's interface with powerful streaming session management:

```python
from nanovllm import StreamingLLM, StreamingConfig, SamplingParams

# 1. Initialize Engine with Streaming Config
llm = StreamingLLM(
    "/YOUR/MODEL/PATH", 
    streaming_config=StreamingConfig(
        dialogue_window=20,  # Keep last 20 turns in KV Cache
        history_window=0,    # Disable text history sink for strict agent prompts
        initial_padding=8,
    ),
    enforce_eager=False,     # Enable CUDA Graph
    tensor_parallel_size=2,
    is_multimodal=True
)

sampling_params = SamplingParams(temperature=0.0, max_tokens=30)

# 2. Create a persistent session
session_id = llm.create_session("You are an experienced GUI Agent...", sampling_params)

# 3. Chat with infinite stream (KV Cache is automatically managed)
# pixel_values and image_grid_thw are generated by HF AutoProcessor
response = llm.chat(
    session_id=session_id, 
    message="current position [0][0]", 
    pixel_values=your_pixel_values, 
    image_grid_thw=your_grid_thw
)

print(response) # e.g. <|action_start|>324 3 0 ; W ; W ; W<|action_end|>
```

## Benchmark
See `benchmark_gui_agent.py` and `livesports3kcc.py` for benchmarks.

### 1. GUI Game Agent (Real-time Action Prediction)
**Test Configuration:**
- Hardware: 8x NVIDIA 80G A800 GPUs (TP=8)
- Model: Qwen3-VL-8B (Fine-tuned for GUI Agent)
- Scenario: Continuous multi-turn interaction with high-res screenshots.

**Performance Results:**
| Inference Engine | Scenario | Throughput (tokens/s) | Real-time Interaction |
|----------------|----------|-----------------------|-----------------------|
| vLLM (Native)  | 20 Turns | ~15 t/s (Re-prefill drop) | ✗ Stutters after 10 turns |
| **Streaming-vLLM** | 100+ Turns | **~120 t/s** | **✅ 24 Hz silky smooth** |

*Note: Streaming-vLLM achieves an **8x speedup** over native vLLM in long-context scenarios by completely eliminating Prefix Cache miss re-prefilling.*
